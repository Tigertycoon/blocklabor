# Optional workshop world

This is a fresh-player export of the local Blocklabor world for Minecraft 1.21.1.
Use the pinned full pack before opening it. Copy `Blocklabor/` into the instance's
`saves/` directory. Player inventories, statistics, quest progress, team data,
claims, waypoints, logs and local server addresses are excluded.

The terrain and entities are retained. This is a teaching/prototype world, not a
claim of a completed adventure map. A complete classroom playthrough remains a
manual check; see `docs/validation.md`.
