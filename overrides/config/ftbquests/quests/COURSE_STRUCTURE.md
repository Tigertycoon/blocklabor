# Blocklabor course structure

Minecraft 1.21.1 / NeoForge. German teaching content is stored under `en_us`
as the fallback locale, so it also appears on clients using another language.

| Module | Quests | Entry requirement | Exit milestone |
| --- | ---: | --- | --- |
| CC:Tweaked | 5 | None | M1-E: Turtle Loop Challenge |
| Super Factory Manager | 4 | M1-E | M2-C: System-Verstaendnis |
| Psi | 5 | M2-C | M3-D: Loopcasting Praxis |
| KubeJS | 4 | M3-D | M4-C: Event in Aktion |

The three bonus quests are optional. Item submissions verify in-game artifacts;
the facilitator checks the program, explanation and demonstration. Quest
completion alone is not an automated assessment of programming skill.
