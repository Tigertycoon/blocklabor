# Storage Optional: Bestands-Alarm (SFM)

## Lernziel

Kinder verstehen:

- Wie man Bestandswerte als "Daten" sieht
- Wie man Grenzwerte definiert
- Wie ein System auf Daten reagieren kann

## Aufgabenidee

1. Lege ein Lager mit Kohle an.
2. Definiere zwei Grenzen:
   - niedrig: unter 32
   - ok: 32 bis 128
3. Gib eine sichtbare Rueckmeldung:
   - Lampe an bei "niedrig"
   - Lampe aus bei "ok"

## Warum diese Aufgabe gut ist

- direkt sichtbar
- keine komplizierte Mathematik
- starker Uebergang von Minecraft zu Informatiklogik

## Erweiterung (Bonus)

- zweites Material (z. B. Holz) mit eigener Grenze
- "Notfallkiste" automatisch befuellen, wenn Bestand zu klein wird
