# M2-B Materialfluss Blueprint (Beispiel)

## Ziel

- Input: Cobblestone
- Verarbeitung: Teilweise zu Stone / Charcoal (je nach Aufbau)
- Output: getrennte Ausgabe-Container

## Minimaler Ablauf

1. Input lesen.
2. Menge pruefen.
3. In Verarbeitungsblock oder Zielkiste verschieben.
4. Output pruefen.
5. Wiederholen.

## Debug-Tipp

Wenn etwas haengt: nur Schritt 1->2 testen, dann 3, dann 4.
